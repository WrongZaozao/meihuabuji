# 梅花卜记

问一件事，起一卦，用卦给的体与器跟对手打一局，按打法得一支签。

## 流程

1. 起卦。输入所问，或直接随机起卦。
2. 得卦。本卦、互卦、变卦、动爻，拆成你和对手的体与器。
3. 对局。按住自己的体或器，拖到对方身上松手出手。
4. 落签。打完出签。

## 规则

- 体归零即负。器是兵器也是护甲，归零就裸。
- 器出手看五行：克 2 格，比和 1 格，被克 0 格且自损 1。
- 体出手不看五行：1 格，自损 1；旺位 2 格不自损。
- 卦气五档死囚休相旺。死：体不能出手，受击穿甲。囚：只能打对方的器。休：伤害 −1。相：正常。旺：可破甲，受击 +1。
- 同一部位连用三次到旺，第四次断，体减半。
- 自疗：器生体时，体 +1、气 +1、器 −1。转化：体器比和时，器 −2 换体 +1。御：每局三次，受击 −1。
- 对方在旺位时喂它一口「生」，它自己就断。
- 第 12 回合后，双方每回合末体 −1。

## 签

- 五档：大凶、凶、平、吉、上吉。
- 签面两句：一句景，按本卦；一句劝，按体用关系。
- 附一句此局（体用关系、回合、余格），宜忌各两项，应期只给速或缓。
- 输局里护住体可判吉，一味拿体换血判大凶。
