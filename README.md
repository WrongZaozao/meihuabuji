# 梅花卜记

> 以你打开它的这一刻起一卦。卦给你一副身体、一个对手、一局天时；打一场，卦还你一支签。

单机 · 离线 · 一局 5–10 分钟 · 一个 HTML 文件。

---

## 这是什么

一个**能对局的卦签生成器**。

起卦不是弹个签文给你，而是**把卦摊成一副牌**：本卦、互卦、变卦拆成你和对手的「体」与「器」，
五行生克决定谁打得动谁，卦气（死囚休相旺）决定你这一手能不能出手。
你按规则打完一局，程序再按**你打成什么样**，把这支签写出来。

所以同一卦，不同打法，签不一样：

- 打得漂亮，签会往上走；打得难看，往下走；
- **明知要输却把体护住了**，它可以判「吉」；**一味拿体换血、一次不防**，那必然「大凶」。

卦给起点，人定终局。

## 怎么玩：五步

| 步骤 | 你做什么 |
|---|---|
| **一 · 问事** | 想一件事（十二字以内，不写也行），点「问事起卦」；或直接「随机起卦」 |
| **二 · 得卦** | 看本卦 / 互卦 / 变卦，以及动爻；这就是这一局的所有零件 |
| **三 · 观用** | 看双方的体、器、五行、卦气，以及对手的「性」（由动爻决定） |
| **四 · 对局** | **按住你的「体」或「器」，拖到对方身上松手**——出手；也可点下方的自疗 / 转化 / 御 |
| **五 · 落签** | 一局打完，出签；可保存图片、复制文字，或再起一卦 |

## 对局：三个位置，两种手段

| 位置 | 是什么 |
|---|---|
| **体** | 你的命。归零即负 |
| **器** | 你的兵器，也是护甲；归零＝「裸」 |
| **用** | 对手的体（梅花以体用分主客，所以敌人叫「用」） |

每局 **体 5 格 / 器 5 格，上限各 7 格**（体器之间的五行关系会先各 ±1）。

出手用哪个位置，就是哪种手段：

| 手段 | 规则 |
|---|---|
| **器** → 看五行 | 克对方 **2 格**；比和 **1 格**；被克 **0 格且自损 1** |
| **体** → 不看五行 | 固定 **1 格**，自己 **−1**（在「旺」位则 2 格且不自损） |

五行关系表（只管器）：

| 关系 | 结果 |
|---|---|
| 我克它 | 有效，打 2 格 |
| 比和 | 有效，打 1 格 |
| 我生它 | **资敌**：对方回 1 格；打的是体还会推它卦气 +1 |
| 它生我 | **得资**：我出手的部位 +1 格 |
| 它克我 | **被制**：打不动，自损 1 格 |

**卦气五档**（贴在体旁边的小格子）：

| 档 | 效果 |
|---|---|
| **死** | 体不能出手；受击时器不吸伤；回合末 体 −1 |
| **囚** | 够不着人：只能打对方的器 |
| **休** | 伤害 −1；回合末 体 +1 |
| **相** | 正常；回合末 体 +1 |
| **旺** | 体出手 2 格且不自损；可放卦气技；受击 +1 |

**过旺则断**：同一个部位连用三次 → 卦气直上「旺」；**第四次还用它 → 断，体减半**。
界面上的「连N」就是数这个的。

**三件常驻动作**（不能用会写明原因）：

- **自疗**：器生体时可用，体 +1、卦气 +1、器 −1；
- **转化**：体与器比和时可用，器 −2 换 体 +1；
- **御**：每局 **3 次**，受击 −1。

**两个反直觉的点**（教学关里都能动手试）：

1. **资敌**：对方已在「旺」位时，你故意喂它一口「生」——它自己就断了（体减半）。
   有时候最好的攻击，不是打它，是给它。
2. **过刚则断**：自己补到旺还继续补，也会断。

**天时**：过了第 12 回合，双方每回合末 体 −1，保证收局。

## 卦签怎么读

| 部分 | 说明 |
|---|---|
| **签等**（最大那个字） | 大凶 / 凶 / 平 / 吉 / 上吉 |
| **判词 · 两句** | 第一句是**景**（按本卦写，64 卦各两句）；第二句是**劝**（按体用关系 × 签等写）。景不落事，劝不落判 |
| **此局** | 一句事实：体用关系、回合数、你剩几格 |
| **宜 / 忌** | 各两项，短的 |
| **应期** | 只给一个字：**速** 或 **缓** |

签等的算法（平为底）：

```
赢：吉 起算，卦顺 +1 / 卦逆 −1，打得漂亮再 +1
输：平 起算，卦顺 +1 / 卦逆 −1
   · 护体手段（自疗/御/转化）≥3 且撑到中后段 → 至少判「吉」   ← 输得体面
   · 一次防都没做、还连用体换血         → 判「大凶」           ← 自弃其体
```

判词库：景 **128 句**（64 卦 × 2）+ 劝 **100 句**（5 关系 × 5 档 × 4）+ 特例 8 句，
全部是四字两句；同一卦打成不同样子，措辞会不同。

## 两种起卦

| | 问事起卦 | 随机起卦 |
|---|---|---|
| 依据 | 年月日时的干支 | 毫秒数当「报数」 |
| 月令 / 四柱 / 节气 | 按此刻 | **仍按此刻** |
| 问事弹窗 | 会弹 | 直接出卦 |
| 可复现 | 同一分钟同一卦 | 同一个毫秒同一卦 |

**全程没有 `Math.random`**——起卦读的是真实时间，所以同一个时刻永远得到同一卦。
这是刻意的：结果可复现，才能被检验。

## 声音

没有音频文件，全部用 WebAudio 现场合成，按**五行 → 五音**取音高：

| 五行 | 木 | 火 | 土 | 金 | 水 |
|---|---|---|---|---|---|
| 五音 | 角 | 徵 | 宫 | 商 | 羽 |

克是「该五行的音 + 上方五度」，耗是低八度闷响，断是一记 70Hz 的低频。
顶栏右上角 `♪` 可关（状态记在本地）。

## 工程

| | |
|---|---|
| 产品 | [`梅花卜记.html`](梅花卜记.html)（开发版，外链 `src/engine.js` 与字体） |
| 单文件 | [`dist/index.html`](dist/index.html) — 1.4 MB，字体 base64 + 规则层内联，**零外部请求** |
| 规则层 | [`src/engine.js`](src/engine.js) — 无 DOM 依赖，纯函数，产品页与测试台共用 |
| 数值台 | [`测试台.html`](测试台.html) — 开发用，可连跑、调参、看日志 |
| 字体 | [`fonts/`](fonts/JingHuaLaoSong-Subset.ttf) — 京華老宋体子集（约 0.93 MB，只含页面用到的字） |

自检（一条命令）：

```bash
node tools/tune.mjs          # 回归断言 + 1000 局曲线
node tools/parse.mjs 梅花卜记.html 测试台.html   # 内联脚本语法
node tools/build-single.mjs  # 重新打单文件版
node tools/fontsubset.mjs    # 改过文案后重裁字体子集
```

当前数值（体5/器5，1000 局）：平均 **10.2 回合**，中位 11，打满 16 回合 17.4%，
我胜 **50.6%**，卡死 0%。规则细节见 [`01_规则.md`](01_规则.md)，
实现细节见 [`07_前端实现.md`](07_前端实现.md)，设计取舍见 [`05_决策记录.md`](05_决策记录.md)。

### 部署到 GitHub Pages

1. 把 `dist/index.html` 复制到仓库根目录，命名 **`index.html`**；
2. Settings → Pages → Deploy from a branch → `main` / `(root)`；
3. 等一分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。
